# 二、设计风格要求

请严格参考 UI 图的整体方向：

- Apple 风格
- 简洁高级
- 大量留白
- 白色 / 浅灰主背景
- 蓝色作为主要强调色
- 卡片式信息分组
- 圆角容器
- 轻阴影
- 细边框

如果图片与文字说明存在轻微冲突：
- 页面结构以产品需求为准

# 三、5 个页面需要具备的主要元素

## 1. 工作台首页 Dashboard

必须包含：
- 左侧导航栏
- 顶部搜索区
- 页面标题“工作台”
- 统计卡片：
  - 今日新增任务
  - 待处理
  - 待审核
  - 已完成
  - 失败任务
- 工作流进度展示：
  视频提交 → 音频提取 → 转写 → AI分析 → 人工审核 → 自动切割 → 输出完成
- 最近任务列表

---

## 2. 任务列表页 Task List

必须包含：
- 搜索框
- 平台筛选
- 状态筛选
- 排序按钮
- 任务表格
- 状态标签
- 分页样式

任务表格字段：
- 任务名称
- 平台
- 视频时长
- 当前状态
- 候选片段数
- 创建时间
- 操作

---

## 3. 新建任务页 New Task

必须包含：
- 任务名称输入框
- 视频来源：
  - 上传视频
  - 选择 NAS 文件
- 平台类型：
  - 抖音
  - B站
  - 通用
- 单条切片最大时长
- 候选片段数量
- AI 偏好风格
- 右侧流程说明卡片
- “开始处理”按钮

---

## 4. 任务详情页 Task Detail

必须包含：
- 任务标题
- 任务基础信息卡片
- 任务状态概览卡片
- 处理进度时间线
- 转写预览模块
- 日志 / 元信息侧栏

---

## 5. 片段审核页 Clip Review

这是最重要的页面，必须优先认真做。

必须包含：
- 候选片段列表
- 每个片段的：
  - 是否启用
  - 片段标题
  - 开始时间
  - 结束时间
  - 时长
  - 内容摘要
  - 推荐理由
  - 传播价值
- 可以呈现为表格或卡片式列表
- 右侧视频预览占位区域
- 片段时间线样式
- 底部操作按钮：
  - 保存修改
  - 生成切片

# 四、实现方式要求

1. 使用现有技术路线：
   - FastAPI
   - Jinja2
   - HTML/CSS/JavaScript

2. 不要贸然切换到 React / Vue。

3. 优先把页面写得：
   - 结构清楚
   - 样式统一
   - 后续易于继续接后端数据

4. 使用模拟数据填充页面，不要所有内容空白。

5. 请注意页面之间导航可以点击跳转。

6. 如果当前 styles.css 过于简单，可以系统性升级，但要保持结构清晰，不要乱堆样式。

# 内容生产队列实施说明

v2.5.5 的版本、运行与数据兼容验收已完成。v2.6 沿用 FastAPI、SQLite、本地文件和 Windows Worker，不增加队列基础设施。每个相邻 PR 合并后再开新短期分支，整版验收后更新原正式服务。

## PR 顺序

1. **素材目录与登记**：不可变预览、本机路径边界、文件版本、明确确认、幂等登记和素材池页面。先独立验证文件读取，不建立虚假父任务，不复制视频。
2. **批次与任务导入**：冻结 Profile/Prompt/Provider/数量/字幕/生产选项；在一个事务内创建真实任务占位、批次项及 task-bound material_import Job。逐个复制到现有 E 盘托管目录，校验全量内容哈希与媒体，保留外部原片。
3. **受限生产队列与恢复**：claim_job/claim_next_job 同事务限制全局重型并发，复用 token fencing/checkpoint；失败不挡后项，人工等待释放执行槽。AI 不确定计费仍需人工处理，不能无限重发。
4. **预切后人工凭据与 Inbox**：批量任务专属凭据绑定 Run、实际选择/边界、切片版本，所有内容准备/同步/排期入口都验证；旧任务保持兼容。统一投影待审片、字幕、发布复核与异常，不新造状态机。
5. **工作台与整版验收**：聚合生产数据、十视频导入/并发/重启/失败演练、旧流程回归、Windows 实机门禁及原服务升级。真实选片质量继续日常补验。

原计划的“素材池/批量任务”拆成两份，以分开验证目录读取和后台媒体写入。后续数量可按真实风险调整，不合并跨版本开发。

## 素材登记契约（PR1）

用户通过原本机管理入口显式输入目录；扫描只读目录元数据，非递归，最多 1000 个目录项和 200 个视频。拒绝网络/设备/相对/跳转路径，拒绝目录及祖先重解析点、符号链接；映射网络盘同样拒绝。不改变任何全局媒体 allowlist，也不提供从登记路径直接下载任意文件的路由。

预览保存原目录身份、每个文件的完整路径、大小、mtime/ctime、device/inode、排除项与清单哈希，有效期 30 分钟。视频扩展名可登记不代表媒体解码成功。用户选中的 source_key 必须来自该预览；确认时重新核对目录与文件身份，有一个变化则整次事务回滚。相同源路径及元数据版本的重复/并发登记复用 source_materials；相同请求 UUID 只返回原回执，不能携带另一份请求正文。

素材 `identity_sha256` 为元数据 JSON 摘要，**不是视频完整内容哈希**。现阶段不读取几十 GB 视频计算预览哈希、不创建 Task/Job、不调用 AI。原文件之后变化不会覆盖旧登记版本；重新扫描建立新版本。完整内容 SHA-256、来源真实性和解码预检必须由下一阶段导入 Job 再验证，不能仅凭登记记录安全激活任务。

当前预览过期只阻止登记，清单仍作为本机元数据保留；未确认预览的保留/清理将在队列生命周期收尾中处理。浏览器同页丢失响应时复用请求 UUID；刷新后重新扫描可能新增一条登记回执，但唯一 source_key 保证不重复建立素材。下一阶段批次需额外实现跨刷新/重启的完整请求幂等。复制前还需校验实际打开的句柄；目前元数据扫描与 stat 之间没有文件锁，不能作为无竞态的字节复制证明。

## 导入和审核后续必须遵守

- 复用任务插入与 create_or_get_active_job_with_connection，不以普通 active Job 去重替代批次幂等；现有 helper 只比较 task/type，不比较源文件。
- 复制使用临时产物、输入版本/完整哈希和当前租约验证；最终路径和数据库关联在受控提交点激活。迟到的旧 Worker 不能覆盖新租约产物。
- Batch 配置和实际 Run 策略保留证据，不自动跟随正式 Prompt 更新。一个素材按不同策略再次生产必须明确创建新任务。
- 自动任务允许预切；人工确认前不得进入内容准备与排期。reviewed/enabled 不能代替独立人工凭据；切片期间候选被修改不能误记实际成片边界。
- Inbox 按任务、Job、cut、字幕 revision、publish job 及审核凭据查询；不复制另一份待办状态，不加载全量转写/逐行 FFprobe。

## 当前验收与回退

PR1 测试覆盖十文件重复/并发登记、预览后内容/目录变化、事务回滚、过期/非法选择、源码证据不可改、旧库备份恢复，以及 Chrome 1440/390 显式确认/响应丢失重试。正式库仍 19 项迁移，PR1 第 20 项只在隔离测试执行。

功能回退关闭素材入口并保留新增表；原单任务能力独立存在。不得将旧数据库备份覆盖到仍有新增记录的正式库。整版升级仍须 WAL-safe 备份、旧行值比较、实际运行目录/监听父链/版本及页面验收。

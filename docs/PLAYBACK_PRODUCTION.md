# 综艺播放目标规则：正式接入

用户于2026-09-27明确授权接入正式选片流程、部署启用并重启项目。此文件说明工程行为；实际运行结果以 PROJECT_STATUS.md 的部署验收记录为准。

## 新任务的行为

启用后，内容类型仍是 `variety_comedy`，显示“棚内综艺·播放目标”，默认带入专用“综艺·播放目标 v1”Prompt。单文件任务和素材批次均冻结 `comedy-playback-v1` Profile 与 Prompt。旧任务、既有 Job 和分析记录不改写；无 Profile 归属的历史任务新建执行也只绑定兼容旧版，不猜测使用新版。

三阶段使用同一冻结规则：充分召回具体处境与互动；扩展自然连续边界；以片内完整转写复评。旧权重对应的六个字段仍可读取，但新版本定义为原始开头25%、处境与关系反差20%、持续推进20%、结果闭环20%、幽默10%、标题兑现5%。音量、视觉不再改变排序分；可选视觉保留候选核验，综合评审加分仅保留给旧版。

45—150秒为硬范围，60—90秒为偏好。新版不自动补至60秒、不任意截短超长候选；无法形成合法自然边界的扩展返回失败或由模型显式跳过。不会机械要求最终反转出现在前三秒或15秒内。

新分不套用旧78分、65分或笑点75分门槛。A表示全局评审对以下五项都给出肯定证据：原始开头有观看理由、存在信息/处境推进、边界保留原意、结果和回应完整、核心事件可确认。B表示仍待人工判断，保留供审核。字段类型严格验证，缺评或错误响应锁定自动切片。通过门槛后按新分排序，最多选取目标数量，可少选或零条；优先保留通过门槛的重叠版本，避免高分但缺失回应的片段挤掉完整片段。

分数是编辑排序分，不是播放预测；A也不是成片已验收。原有人工成片、字幕、排期与发布边界保持。审核页显示六维名称、门槛依据与原音/画面待核事项。

## 启用和回退

没有启动时自动迁移/启用动作，没有新表或修改旧迁移。显式工具在既有表内新增不可变版本与专用Prompt，然后原子切换 Profile 正式版本指针。默认仅预览；应用必须携带刚预览的当前哈希，拒绝覆盖并发变更。专用Prompt若被用户修改或归档则拒绝覆盖。重复应用不重复建版本。

在正确运行目录、已有数据库备份且确认没有处理中任务时执行。必须使用项目Python并以模块方式运行：

```powershell
python -m scripts.activate_playback_policy --database 'ABSOLUTE_DATABASE_PATH'
python -m scripts.activate_playback_policy --database 'ABSOLUTE_DATABASE_PATH' --apply --expected-sha256 CURRENT_HASH_FROM_PREVIEW
```

回退同样先预览，再携带当前哈希：

```powershell
python -m scripts.activate_playback_policy --database 'ABSOLUTE_DATABASE_PATH' --target legacy
python -m scripts.activate_playback_policy --database 'ABSOLUTE_DATABASE_PATH' --target legacy --apply --expected-sha256 CURRENT_HASH_FROM_PREVIEW
```

回退只改变以后任务的默认策略。已经冻结新版的任务仍需保留支持新版的代码；不能只回退旧代码而使新版快照失去执行支持。无需用旧数据库覆盖后续操作。

# PRD v0.1：牛马片场 / NiuMa Studio

## 1. 产品目标

构建一个 Windows 本地 AI 高光生产后台，把直播录像、综艺访谈和长视频素材转换为可审核、可编辑、可自动切割的短视频候选片段。系统面向个人本地内容生产工作流，首版优先保证稳定、清晰、可扩展。

## 2. MVP 范围

首版必须支持：

- 新建视频处理任务，支持直播录像、综艺访谈和其他长视频素材。
- 上传本地视频，或选择 NAS / 本地目录中的已有视频。
- 每条视频生成独立任务目录。
- 提取音频。
- 转写为带时间戳文本。
- 生成分钟级 / 分段级时间线文本。
- AI 根据时间线分析候选短视频片段。
- 用户设置单条切片最长时长与候选片段数量。
- AI 输出候选片段 JSON。
- 后台查看并编辑候选片段。
- 根据确认后的时间段自动切割视频。
- 输出最终切片文件。
- 后台展示任务状态、处理进度与异常信息。

首版暂不做：

- MacBook 自动录屏。
- 自动识别抖音 / B站直播间并检测是否开播。
- 自动发布到抖音 / B站。
- 自动生成封面。
- 多用户权限系统。

这些能力只在架构上预留接口。

## 3. 业务流程

```text
直播录像 / 视频上传
→ 存入 NAS 或项目任务目录
→ 提取音频
→ 音频转文字，生成带时间戳的文本
→ AI 分析文本，挑出适合短视频传播的片段
→ 输出候选片段 JSON
→ 用户在后台审核和编辑
→ 系统按确认时间段自动切割原视频
→ 输出短视频文件
→ 后台跟踪任务进度
```

## 4. 功能模块

- 任务管理：创建任务、查看任务列表、查看任务详情。
- 文件存储：管理原视频、音频、转写文本、AI 分析结果和切片输出。
- 音频提取：通过 FFmpeg 从视频提取音频。
- 语音转写：预留转写服务接口，输出带时间戳文本。
- 时间线生成：把转写文本整理成分钟级 / 分段级时间线。
- AI 分析：预留 OpenAI-compatible API 或本地模型接口，输出候选片段 JSON。
- 人工审核：用户编辑标题、起止时间、摘要、推荐理由和传播价值。
- 视频切割：通过 FFmpeg 按审核后的片段自动输出短视频。
- 状态跟踪：记录状态、进度、异常信息和处理日志。

## 5. 版本规划

### v0.1 项目骨架

- 建立 FastAPI 主工程。
- 建立页面入口和任务状态草案。
- 建立 SQLite 连接与任务表草案。
- 建立文档与后续开发规范。

### v0.2 任务创建与本地文件管理

- 接入真实文件上传。
- 为每个任务创建标准目录。
- 写入真实任务记录。

### v0.3 FFmpeg 处理链路

- 接入 FFprobe 读取视频信息。
- 接入 FFmpeg 音频提取。
- 接入 FFmpeg 自动切割。

### v0.4 转写与 AI 候选片段

- 接入转写服务。
- 生成时间线文本。
- 接入 AI 片段分析接口。

### v0.5 审核与输出体验

- 完善片段审核页。
- 支持保存编辑结果。
- 支持生成最终切片文件。

# 任务状态流转

## 1. 状态列表

- 待提交视频
- 待处理
- 音频提取中
- 转写中
- 待 AI 分析
- AI 分析中
- 待人工审核
- 切割中
- 已完成
- 失败

## 2. 标准流转

```text
待提交视频
→ 待处理
→ 音频提取中
→ 转写中
→ 待 AI 分析
→ AI 分析中
→ 待人工审核
→ 切割中
→ 已完成
```

## 3. 失败流转

任意处理阶段出现不可恢复错误时，任务进入：

```text
失败
```

失败状态需要记录：

- 出错阶段。
- 错误信息。
- 相关文件路径。
- 是否可以重试。

## 4. 首版进度占比建议

- 待处理：0%
- 音频提取中：10% - 25%
- 转写中：25% - 50%
- AI 分析中：50% - 70%
- 待人工审核：70%
- 切割中：80% - 95%
- 已完成：100%

## 5. 后续需要补充

- 每个阶段的重试策略。
- 每个阶段的日志文件格式。
- 候选片段审核后的状态保存方式。

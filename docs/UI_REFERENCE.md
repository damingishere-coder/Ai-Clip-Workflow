## 2. 设计原则

- Apple 风格。
- 简洁、高级、留白充足。
- 白色 / 浅灰背景。
- 蓝色作为主强调色。
- 轻量玻璃拟态感。
- 卡片式信息分组。
- 清晰、克制，不做密集企业后台风格。
- 首屏应直接进入可用后台，不做营销式落地页。

## 3. 主要页面

左侧导航当前顺序为：工作台、新建任务、任务列表、片段审核、字幕推送、系统状态。

### 1. 工作台首页

包含左侧导航、顶部搜索、任务统计卡片、v1.1 流程展示和最近任务列表。

### 2. 任务列表

包含搜索、平台筛选、状态筛选、排序按钮、任务表格、状态标签和分页样式。

当前任务列表已增加“隐藏”操作。隐藏只从页面列表移除任务，不删除 E 盘任务目录和视频文件。任务列表会展示输出切片数量和“后续工作流”，用于提示切片完成后是否进入“待加字幕 / 待推送”。

### 3. 新建任务

包含任务名称、视频上传、平台类型、单条切片最大时长、候选片段数量和流程说明。

当前新建任务页只保留上传本机视频入口。上传视频会保存到 E 盘任务目录；NAS / 本地路径选择、浏览路径和打开目录入口已从页面移除。

### 4. 任务详情

包含任务基础信息、状态概览、AI 分析、转写预览、输出结果和日志 / 元信息侧栏。

当前标题区会展示任务 ID、写入时间、主题和当前状态，方便用户对照本地任务文件夹。状态概览已合并处理进度时间线，使用地铁路线图节点表达：绿色表示已通过，蓝色表示当前阶段，黄色表示异常或待处理问题。

当前顶部主操作为“开始处理 / 继续处理”，会自动完成“提取音频 → 生成转写 MD”；转写完成后主按钮不可重复点击，只保留明确的“重新生成转写”。“生成切片”不再放在任务详情顶部，只在片段审核页执行。远程 / 本地 AI 分析入口已移入“AI 分析”板块，用户可先填写 AI 偏好；偏好只影响候选片段推荐方向、推荐理由和排序参考，不会直接改变最终成片。转写预览只展示真实带时间戳的转写文本，并提供“查看完整原文”入口；`transcript.md` 默认可由火山引擎远程转写生成，远程失败时按配置退回本地 faster-whisper，文件仍包含分钟级原文整理和逐句时间戳原文。转写进度会自动刷新，并展示当前服务商、模型、设备和计算类型。

### 5. 片段审核

包含候选片段列表、启用开关、标题、起止时间、摘要、推荐理由、传播价值、剪辑建议、AI 来源 / 模型、真实视频预览、片段转写抽屉和生成切片操作。

当前片段审核页不再展示模拟候选片段。没有真实候选片段时显示空状态；有真实候选片段时会从 `clip_candidates` 表读取，并支持保存标题、起止时间、启用状态和摘要修改。右侧面板会读取任务源视频并提供真实播放器，预览栏宽度和视频高度已受控，竖屏视频会完整缩放显示；点击候选片段“播放预览”会跳到对应时间段播放；点击“查看这一段转写”会从右侧打开转写抽屉，显示该片段对应的逐句原文。“生成切片”按钮已接入真实 FFmpeg 切割流程，右侧面板会展示切片输出结果。

片段审核 AI 分析策略已更新：远程 DeepSeek 和本地 Ollama 都使用 3 分钟左右的小段分段分析，再合并、去重、排序候选片段，避免 40 分钟或 1 小时以上转写一次性分析导致 JSON 截断。AI 返回旧字段时会自动兼容，例如 `clip_key` 会转为 `clip_id`，缺失的传播价值会补成可审核字段。任务详情页只展示可读的失败摘要，详细校验错误保留在任务日志。

`/clips` 总览页已升级为片段审核工作台，会展示待 AI 分析、待人工审核、可生成切片、已完成和异常任务统计，并按任务提供“详情”和“进入审核”入口。单任务审核页没有候选片段时，会显示返回任务详情、生成转写和运行远程 AI 分析的下一步按钮。

### 6. 字幕推送

包含切片后视频队列、切片视频预览、字幕样式模板、打码设置和一键推送配置。

当前页面属于切片后的后续工作台：已生成切片会从 `output_clip` 表读取并显示；如果本地文件存在，可以直接播放预览。不满意时可返回片段审核页修改剪切；删除、自动加字幕、打码和推送按钮先作为后续接入入口。字幕样式支持字体、字号、位置、颜色和阴影开关，当前保存到浏览器本地。

### 7. 系统状态

包含 E 盘存储目录、FFmpeg、FFprobe、SQLite 数据库、任务数量和最近异常任务状态。

当前系统状态页已补充推荐运行地址 `http://127.0.0.1:8001`、AI 配置状态、任务状态统计和 AI 配置弹窗。AI 配置弹窗保存到 `.env`，API Key 输入框默认脱敏，留空会保留旧密钥。弹窗头部和底部操作区固定可见，支持点击关闭、取消、遮罩区和 ESC 关闭；本地 AI 区域已简化为 Ollama 模型下拉选择。

系统状态页现在会直接展示远程 AI Base URL、协议、片段审核模型、远程 Key 是否有效，以及本地 Ollama 是否在线和已安装模型。远程 Key 仍不显示明文；如果 Key 为空或明显过短，页面会把 AI 配置标记为异常。远程 AI 默认面向 DeepSeek，推荐 `https://api.deepseek.com`、`deepseek-v4-flash` 和 `chat_completions`；本地 AI 默认推荐 `qwen3:8b`，避免 `qwen3:14b` 在当前机器上长时间超时。

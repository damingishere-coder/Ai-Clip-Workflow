## 2. 设计原则

- Apple 风格。
- 简洁、高级、留白充足。
- 白色 / 浅灰背景。
- 蓝色作为主强调色。
- 轻量玻璃拟态感。
- 卡片式信息分组。
- 清晰、克制，不做密集企业后台风格。
- 首屏应直接进入可用后台，不做营销式落地页。

## 3. 五个主要页面

### 1. 工作台首页

包含左侧导航、顶部搜索、任务统计卡片、MVP 流程展示和最近任务列表。

### 2. 任务列表

包含搜索、平台筛选、状态筛选、排序按钮、任务表格、状态标签和分页样式。

### 3. 新建任务

包含任务名称、视频来源、平台类型、单条切片最大时长、候选片段数量、AI 偏好风格和流程说明。

### 4. 任务详情

包含任务基础信息、状态概览、处理进度时间线、转写预览和日志 / 元信息侧栏。

### 5. 片段审核

包含候选片段列表、启用开关、标题、起止时间、摘要、推荐理由、传播价值、视频预览占位和生成切片操作。
